### How to Install in Chrome:
1. Download and extract [Fokas-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/Fokas-v1.0.0.zip).
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extracted `Fokas` folder.
6. Done! Click the extension icon in your Chrome toolbar to launch `fokas.`.

## 🔥 Key Features

- **🐾 Fokas Cat Focus Enforcer**: Select allowed/whitelisted tabs. Switching to non-allowed tabs triggers an instant full-screen Angry Cat overlay (`BAND KRRR BSDKS!! 🚫 🤬`) and alarm sound.
- **🔊 Customizable Violation Meme Sounds**: Choose from dropdown menu sounds including:
  - 🔥 *Chodu CID Meme* (`chodu-cid.mp3`)
  - 🎧 *CID Voicemod* (`cid-made-with-Voicemod.mp3`)
  - 🤬 *Kya Cheda Bhosdi* (`kya-cheda-bhosdi.mp3`)
  - 🚨 *iOS SOS Alarm* (`ios_sos_alarm.wav`)
  - 🔊 *Emergency Alert* (`alert.mp3`)
  - 📣 *Siren Chime* (`alert.wav`)
- **⏱️ Focus Timer & Stopwatch**: Customizable countdown timer with presets (5m, 25m, 50m) and precise stopwatch with lap recording.
- **📌 Frameless Floating Sticky Note**: Drag-and-drop Picture-in-Picture (PIP) floating sticky note that floats over any application or tab with custom typography & color palettes.
- **📋 Custom Task Countdown List**: Add custom tasks with dedicated timer counters and progress indicators.
