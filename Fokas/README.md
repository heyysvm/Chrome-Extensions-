# Fokas — Focus, Timer, Floating Notes & Cat Companion

Stay focused with customizable timers, stopwatches, frameless floating sticky notes with full color and font palettes, mini floating view, and cat tab navigation focus enforcer.

---

## Direct Download & Installation

### Direct ZIP Download
Download the pre-packaged extension ZIP:
- **Direct Download Link**: [Fokas-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/Fokas-v1.0.0.zip)

### Installation Steps:
1. Download and extract [Fokas-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/Fokas-v1.0.0.zip).
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extracted `Fokas` folder.

## Key Features

- **Fokas Cat Focus Enforcer**: Select allowed/whitelisted tabs. Switching to non-allowed tabs triggers a full-screen red SOS overlay and alarm sound.
- **Customizable Violation Sound Effects**: Choose from dropdown menu options including:
  - `Chodu CID Meme` (`chodu-cid.mp3`)
  - `ACP Kyu Re Maderchod` (`acp-kyu-re-maderchod-made-with-Voicemod.mp3`)
  - `CID Pradyuman Bhenchod` (`CID ACP Pradyuman bhenchod.mp3`)
  - `CID Chut Mari Ja Rahi` (`cid chut mari ja rahi hai meme sound.mp3`)
  - `CID Kya Bak Rahe Ho` (`Cid kya bak rahe ho meme sound.mp3`)
  - `Aaaa Chud Gayi Chud Gayi` (`aaaa-chud-gayi-chud-gayi.mp3`)
  - `CID Voicemod` (`cid-made-with-Voicemod.mp3`)
  - `Kya Cheda Bhosdi` (`kya-cheda-bhosdi.mp3`)
  - `iOS SOS Siren` (`ios_sos_alarm.wav`)
  - `Emergency Alert` (`alert.mp3`)
  - `Siren Chime` (`alert.wav`)
- **Focus Timer & Stopwatch**: Countdown timer with presets (5m, 25m, 50m) and precise stopwatch with lap recording.
- **Frameless Floating Sticky Note**: Drag-and-drop Picture-in-Picture (PIP) floating sticky note that floats over any desktop application with custom typography and color palettes.
- **Custom Task Countdown List**: Add custom tasks with dedicated timer counters and progress indicators.

## Technical Stack

- Manifest V3 (Chrome Extension)
- HTML5 / CSS3 (Glassmorphism UI)
- Vanilla JavaScript ES6+
- Offscreen Document Audio API for background sound playback
- Document Picture-in-Picture API
