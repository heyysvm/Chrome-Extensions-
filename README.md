## Installation Guide (3 Steps)

1. **Download ZIP**: Click any download link in the table above to download the `.zip` archive.
2. **Extract Archive**: Extract the downloaded `.zip` file on your computer.
3. **Load in Chrome**:
   - Open Google Chrome and navigate to `chrome://extensions`.
   - Toggle **Developer mode** to **ON** (top-right corner).
   - Click **Load unpacked** (top-left corner).
   - Select the extracted extension folder.

## Suite Overview

### 1. [DevLens](./DevLens) — Developer & Designer HUD, Code Utilities & Micro-Break

A universal developer and designer HUD featuring a live element CSS inspector, color token sampler, developer text transformers, interactive cheat sheets, and a micro-break code quiz game.

- **Direct Download**: [DevLens-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/DevLens-v1.0.0.zip)
- **Key Features**:
  - **Live CSS & Color Inspector**: Hover any webpage element to inspect fonts, dimensions, and hex colors. Click to save color tokens.
  - **CSS Palette Exporter**: Export saved color tokens into CSS custom variables (`:root { ... }`).
  - **Code Utilities**: Built-in JSON beautifier, Base64 encoder/decoder, and URL encoder.
  - **Interactive Cheat Sheets**: 1-click copy code reference for Git, CSS Flexbox, HTTP Status Codes, and Regex.
  - **Micro-Break Dev Quiz Game**: Interactive 60-second code quiz game with high-score tracking.
  - **Floating PIP Notepad**: Drag-and-drop Picture-in-Picture scratchpad that floats over desktop apps.
