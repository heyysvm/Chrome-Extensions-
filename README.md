# 🧩 Chrome Extensions Repository

A curated collection of Chrome extensions designed for productivity, focus, and system tracking.

---

## 📂 Included Extensions

### 1. 🐾 [fokas.](./Fokas) — Focus, Timer, Floating Notes & Cat Companion
Stay focused with customizable timers, stopwatches, frameless floating sticky notes, mini floating PIP view, and cat tab navigation focus enforcer with meme sound effects (`Chodu CID`, `Kya Cheda Bhosdi`, etc.) and full-screen overlay.
- [📦 **Direct 1-Click ZIP Download (Fokas-v1.0.0.zip)**](./Fokas-v1.0.0.zip)

### 2. ⚡ [NetSpeedTracker](./NetSpeedTracker)
Track real-time network speeds and data usage directly from your Chrome toolbar.

### 3. 📝 [Notes_ext](./Notes_ext)
Quick sticky notes extension for saving thoughts, code snippets, and to-do lists.

### 4. 🧠 [internet-memory](./internet-memory)
Bookmark and memory search extension for managing internet research and history.

---

## 📥 How to Install Any Extension in Chrome

1. Clone or download this repository (or download the `.zip` file for specific extensions).
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Toggle on **Developer mode** in the top right.
4. Click **Load unpacked** and select the folder of the extension you want to install (e.g. `Fokas`).
