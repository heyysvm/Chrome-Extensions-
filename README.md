## 🛠 How Anyone Can Install it in Chrome (3 Steps)

### Method 1: Using the 1-Click ZIP (Easiest)
1. Click the download button above or open [Fokas-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/Fokas-v1.0.0.zip).
2. Unzip/extract the downloaded `Fokas-v1.0.0.zip` file on your computer.
3. Open Google Chrome, go to `chrome://extensions`, turn ON **Developer mode** (top-right), click **Load unpacked** (top-left), and select the extracted folder!

### Method 2: Downloading Full Repository ZIP
1. At the top of this GitHub repository page, click the green **`<> Code`** button.
2. Select **`Download ZIP`**.
3. Extract the ZIP and load the folder in `chrome://extensions`.
