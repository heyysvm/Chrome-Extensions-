## 🛠 How to Install Any Extension in 3 Steps

1. **Click any download button above** to download the extension `.zip` file.
2. **Unzip/Extract** the downloaded `.zip` file into a folder on your PC.
3. Open **Google Chrome**, navigate to `chrome://extensions`:
   - Toggle **Developer mode** ON (top-right switch).
   - Click **Load unpacked** (top-left button).
   - Select the extracted folder. Done! 🎉
