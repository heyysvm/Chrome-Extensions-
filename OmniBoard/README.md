# 📋 OmniBoard — Floating Clipboard & Snippet Power-Tool

OmniBoard is a Chrome Extension that automatically captures copied text, links, code snippets, and colors across the web, giving you a **frameless floating Picture-in-Picture (PIP) clipboard manager**, 1-click text transformers, and AI prompt presets.

## 🔥 Key Features

- **🚀 Frameless Floating PIP Board**: Click *Floating PIP* to launch a persistent, floating Picture-in-Picture window that stays on top of all desktop apps on Windows!
- **📋 Auto-Capture Copy History**: Automatically saves text, URLs, hex color codes, JSON objects, and code snippets whenever you copy text (`Ctrl + C`) on any website.
- **⚡ Power Text Transformers**: 
  - 🧹 *Strip Clean*: Remove HTML tags, formatting, and extra spaces.
  - 🔡 *Case Converters*: Convert text to `UPPERCASE`, `lowercase`, or `Title Case`.
  - 💻 *JSON Format*: Beautify and format messy JSON strings automatically.
  - 🤖 *AI Prompt Templates*: 1-click prepend AI prompts for ChatGPT, Gemini, and Claude (*Refactor Code*, *Summarize*, *Fix Grammar*).
- **📌 Pin & Favorite Snippets**: Pin essential links and snippets so they never get cleared.
- **🔍 Instant Fuzzy Search**: Search across your clipboard history in real-time.

## 🛠 Installation

1. Download and extract [OmniBoard-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/OmniBoard-v1.0.0.zip).
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Toggle ON **Developer mode** in the top-right corner.
4. Click **Load unpacked** (top left) and select the extracted `OmniBoard` folder.
5. Done! Click the 📋 icon in your toolbar or copy text anywhere to see OmniBoard in action!
