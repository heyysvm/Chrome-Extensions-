# OmniBoard — Floating Clipboard & Snippet Power-Tool

OmniBoard is a Chrome Extension that automatically captures copied text, links, code snippets, and colors across the web, giving you a frameless floating Picture-in-Picture (PIP) clipboard manager, 1-click text transformers, and persistent local storage.

---

## Direct Download & Installation

### Direct ZIP Download
Download the pre-packaged extension ZIP:
- **Direct Download Link**: [OmniBoard-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/OmniBoard-v1.0.0.zip)

### Installation Steps:
1. Download and extract [OmniBoard-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/OmniBoard-v1.0.0.zip).
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Toggle **Developer mode** to **ON** in the top-right corner.
4. Click **Load unpacked** (top left) and select the extracted `OmniBoard` folder.

## Key Features

- **Frameless Floating PIP Board**: Click *Floating PIP* to launch a persistent, floating Picture-in-Picture window that stays on top of desktop applications.
- **Continuous Local Capture**: Automatically saves copied text, URLs, hex color codes, JSON objects, and code snippets into Chrome local storage (`chrome.storage.local`).
- **Dedicated 1-Click Actions**: Every item in the list features explicit **Copy Item**, **Pin**, and **Delete** buttons.
- **Text Transformers**:
  - `Strip Clean`: Remove HTML tags, formatting, and extra spaces.
  - `Case Converters`: Convert text between UPPERCASE, lowercase, and Title Case.
  - `JSON Beautifier`: Auto-formats and indents messy JSON strings.
  - `AI Prompt Templates`: Prepend AI prompts for ChatGPT, Gemini, and Claude (*Refactor Code*, *Summarize*, *Fix Grammar*).
- **Pin & Favorite Snippets**: Pin essential links and snippets so they remain saved.
- **Search & Clear**: Real-time fuzzy search across stored clips, with options for clearing unpinned items or wiping all storage.
