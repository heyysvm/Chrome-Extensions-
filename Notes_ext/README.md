## Features

- **Instant Auto-Save**: Automatically saves notes locally as you type.
- **Distraction-Free UI**: Minimalist, clean popup for quick note taking.
- **Persistent Storage**: Retains notes across browser restarts.

## Installation

1. Download and extract [Notes_ext-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/Notes_ext-v1.0.0.zip).
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the `Notes_ext` folder.
