# Internet Memory — AI-Powered Browser History & Semantic Search

Internet Memory is a Chrome Extension and Web Dashboard that replaces standard browser history with natural language semantic search and Retrieval-Augmented Generation (RAG) AI chats over your browsing past.

---

## Key Features

- **Semantic Search**: Query history by meaning: *"the tutorial about MongoDB transactions I read last week"* or *"FastAPI JWT setups"*.
- **Conversational RAG Chat**: Ask questions directly to your browsing history with AI citation links.
- **Webpage Content Purger**: Content script automatically extracts readable text, stripping navbars, footer layouts, sidebars, and ads.
- **Dashboard & Timeline**: Dark/light mode dashboard presenting chronological history, metrics, reading speed statistics, and difficulty breakdowns.
- **Folder Collections**: Group relevant pages together into custom collection spaces.
- **Privacy Rules**: Define domains and keyword exclusions to prevent sensitive websites from being indexed.

## Installation Steps in Chrome

1. Download and extract [internet-memory-v1.0.0.zip](https://github.com/heyysvm/Chrome-Extensions-/raw/main/internet-memory-v1.0.0.zip).
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (toggle on top-right).
4. Click **Load unpacked** (top-left).
5. Select the extracted folder.
